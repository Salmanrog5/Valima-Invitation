NIKKAH & VALIMA INVITATION WEBSITE

1. Open index.html to preview the website.
2. Keep index.html, styles.css, script.js and the assets folder together.
3. To publish on GitHub Pages:
   - Create a new GitHub repository.
   - Upload all files and the assets folder.
   - Open repository Settings > Pages.
   - Select Deploy from a branch, choose main/root, then Save.
4. The live invitation link will appear in GitHub Pages settings.

Notes:
- Background audio starts only after the guest taps Open Invitation, as required by mobile browsers.
- RSVP has intentionally not been included.
